## 看懂低价年付VPS配置表的几个细节

参数表里真正决定体验的是存储类型、CPU 是否共享、端口速率和 IPv4 有无，价格反而不是唯一指标。

- **存储看类型**：NVMe SSD > 普通 SSD > HDD。看到 $31.20/年 只给 5GB HDD 的机型（JustHost 就有这种配置），要知道那是给纯备份或极轻用途准备的，拿来建站会很难受。
- **CPU 看标注**：同价位标 AMD（Ryzen / EPYC）的一般优于普通 Intel 低配；标 Fair Share（共享核心）的，比如 ByteVirt 的 2(s)，意思是和别人分核，并非独占 2 核。
- **流量和端口分开看**：1.5TB @500Mbps 和 4TB @1Gbps 是两种完全不同的体验，月流量决定能跑多少，端口速率决定跑多快。
- **IPv4 有无很关键**：CloudCone 有 $14.99/年 的 IPv6-only 机型，没有 IPv4 意味着国内大部分网络直连访问不了；个别超低价档（如台湾 $12/年）给的是 NAT 共享 IPv4、20 个端口转发，没有独享 IP，建站基本没戏。除非明确不需要 v4，否则这类机型别碰。

## 便宜年付VPS的三个常见问题

**这么便宜会不会跑路？** 年付本质是预付费，风险确实比月付高。能做的功课有三件：优先选运营时间长、有自有网络的厂商（Hostodo 2014 年至今，自有 AS 网络）；下单前从自己的网络 ping 一下厂商提供的测试 IP 或 looking glass；第一年只投入亏得起的金额。

**能用支付宝付款吗？** 分厂商。Hostodo 支持支付宝，DigitalVirt 支持支付宝加微信；RackNerd 以 PayPal、信用卡为主，结算页会列出当前支持的付款方式，下单前看一眼即可。
